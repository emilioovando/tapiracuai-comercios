Política de privacidad

Tapiracuai Comercios

Última actualización: 29 de junio de 2026

1. Datos que podemos recopilar

Según el uso de la plataforma, podemos recopilar:

  • Nombre y apellido.
  • Teléfono o WhatsApp.
  • Correo electrónico.
  • Barrio, zona o dirección de entrega.
  • Datos del comercio y responsable.
  • Logos, fotos y productos cargados.
  • Pedidos, consultas, disponibilidad y mensajes relacionados.
  • Datos técnicos básicos, como dispositivo, navegador, fecha, hora y actividad dentro de la app.
  • Ubicación aproximada o precisa solo si el usuario la autoriza para funciones de mapa o delivery.

2. Para qué usamos los datos

Usamos los datos para:

  • Mostrar comercios y productos.
  • Conectar clientes con comercios.
  • Enviar consultas o pedidos por WhatsApp.
  • Administrar registros de comercios.
  • Aprobar, destacar o suspender comercios.
  • Mostrar disponibilidad, precios y estados de pedido.
  • Mejorar la seguridad, el funcionamiento y la experiencia de la app.
  • Enviar avisos importantes sobre la plataforma.

3. Datos compartidos con comercios

Cuando el cliente arma un pedido o consulta, se puede compartir con el comercio: nombre, barrio, dirección si corresponde, productos, cantidades, total estimado, nota y canal de contacto.

4. Datos compartidos con terceros

Podemos usar servicios externos para hosting, base de datos, analítica, mapas, autenticación, correo, WhatsApp, Meta/Facebook/Instagram o herramientas similares. Solo se comparten los datos necesarios para operar la plataforma.

5. Fotos, logos e imágenes

Las imágenes cargadas por clientes o comercios se usan para mostrar perfiles, comercios, productos o comprobantes dentro de la app. El usuario o comercio debe tener derecho a usar esas imágenes.

6. Ubicación

La ubicación se usa solo si el usuario la autoriza. Puede servir para mapas, zonas de delivery, comercios cercanos o seguimiento de pedido. En una primera etapa, el seguimiento puede ser estimado y no en tiempo real.

7. Seguridad

Aplicamos medidas razonables para proteger cuentas, contraseñas, datos de comercios, pedidos y datos personales. Las contraseñas no se almacenan en texto visible y la autenticación se gestiona mediante servicios seguros.

8. Conservación de datos

Los datos se conservan mientras sean necesarios para operar la cuenta, pedidos, historial, soporte, cumplimiento legal o seguridad. El usuario puede solicitar la eliminación o corrección de sus datos por el canal oficial.

9. Derechos del usuario

El usuario puede solicitar acceso, corrección, actualización o eliminación de sus datos, sujeto a verificaciones razonables de identidad y a las obligaciones legales o comerciales aplicables.

10. Menores de edad

Tapiracuai Comercios no está dirigida específicamente a menores de edad. Cuando corresponda, el uso por menores debe realizarse con autorización o supervisión de sus padres o responsables.

11. Contacto de privacidad

Las solicitudes relacionadas con privacidad y datos personales pueden realizarse a través de los canales oficiales de contacto disponibles dentro de Tapiracuai Comercios.
